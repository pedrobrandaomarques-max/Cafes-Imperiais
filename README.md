# ☕ Cafés Imperiais

**Meu primeiro projeto de desenvolvimento web | Curso básico de HTML e CSS — SENAC**

O **Cafés Imperiais** é um site demonstrativo de cafeteria, desenvolvido para colocar em prática meus primeiros conhecimentos em criação e estilização de páginas web. O projeto apresenta produtos, um cardápio e uma área de contato, com navegação entre páginas e efeitos visuais feitos com CSS.


## Como surgiu o projeto

Este foi **o primeiro site que criei**, durante o curso básico de **HTML e CSS no SENAC**. Meu objetivo era sair da teoria e começar a entender, na prática, como estruturar uma página, organizar o conteúdo, trabalhar com imagens e construir um layout usando CSS.

Guardo este projeto como um marco do início da minha trajetória na programação. Hoje, continuo desenvolvendo esses conhecimentos na graduação em **Engenharia de Software na Universidade Cidade de São Paulo (UNICID)**.

## Objetivos de aprendizagem

- Estruturar páginas utilizando **HTML5**.
- Aplicar estilos, cores, espaçamentos e organização visual com **CSS3**.
- Criar menus de navegação e conectar páginas do mesmo site.
- Organizar elementos com **CSS Flexbox**.
- Experimentar efeitos de interação com `:hover`.
- Praticar a criação de formulários HTML.
- Dar os primeiros passos com **media queries** para diferentes tamanhos de tela.

## Páginas do site

| Arquivo | Conteúdo |
| --- | --- |
| `index.html` | Página inicial com banner, apresentação da cafeteria e destaques como croissant, sucos e torta de limão. |
| `Cardapio.html` | Galeria de produtos do cardápio, organizada em cartões com efeito de ampliação ao passar o mouse. |
| `Contato.html` | Formulário de contato com campos de nome, e-mail, telefone, data e mensagem. |
| `Formulario.html` | Exercício adicional de formulários HTML, com diferentes tipos de campos e agrupamentos. |

## 🛠️ Tecnologias utilizadas

- **HTML5:** estrutura e conteúdo das páginas.
- **CSS3:** aparência, layout e efeitos visuais.
- **Flexbox:** alinhamento e distribuição de elementos.
- **Media queries:** primeiras regras de adaptação para telas menores.
- **GitHub Pages:** publicação da versão estática do site.
